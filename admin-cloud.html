📖 快速开始指南

  1. 访问 supabase.com 注册账号（推荐用GitHub登录）
  2. 点击 "New Project" 创建新项目（选择 Tokyo 区域）
  3. 进入项目 → 左侧 Settings → API
  4. 复制 Project URL 和 anon public key 到上方输入框
  5. 点击 "保存配置并连接"
  6. 然后进入左侧 SQL Editor，打开 supabase-init.sql 文件，复制全部内容粘贴执行
  7. 完成！现在可以使用下方管理功能了 ✨
